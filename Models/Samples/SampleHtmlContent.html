About This Content

This is a dynamically rendered HTML content page served from the Portal application. The content is stored in the database and rendered with full styling support.

Key Features

  • Dynamic HTML content from database
  • Full CSS styling support
  • Responsive design
  • Easy to manage and update

Getting Started

To create your own custom content pages:

  1. Create a PortalContent entry with a name and reference
  2. Create corresponding PortalContentData entries with HTML content
  3. Add the ContentDataID reference to the PortalContent JSON data
  4. Access the content through the portal viewer
