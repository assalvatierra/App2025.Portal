## 🎯 Get Started

### 1. Run Locally
```bash
# In Visual Studio
# F5 to Debug
# Open browser, hit a page with database calls
# Check Output → Debug → Look for SQL traces
```

### 2. Deploy to Production
```bash
# Set environment variable
export OTEL_EXPORTER_OTLP_ENDPOINT=http://jaeger:4317

# Or use appsettings.Production.json
```

### 3. View Traces
- **Locally**: Console output (real-time)
- **Jaeger**: http://localhost:16686
- **Grafana**: Search in Tempo datasource
- **Datadog**: APM > Traces

## 🐛 Troubleshooting

| Problem | Solution |
|---------|----------|
| No traces | Check `OpenTelemetry:Enabled = true` |
| Can't see console output | Check `ConsoleExporter = true` in dev |
| Sensitive data | Use parameterized queries |
| Too many traces | Lower `SamplingRatio` |
| Performance impact | Enable sampling in production |
